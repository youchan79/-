# 소셜 로그인 설정 (카카오 · 네이버 · 구글)

로그인 창에 "카카오로 계속하기", "네이버로 계속하기", "Google로 계속하기" 버튼을 켜는 방법입니다.
**셋 다 무료**입니다. 키를 넣기 전까지 그 버튼은 안 보이고, 지금처럼 이메일 로그인만 됩니다.
(애플 로그인은 유료 개발자 등록이 필요해서 넣지 않았습니다.)

- 운영 주소: `https://studyai-l12f.onrender.com` (`l12f`의 `l`은 소문자 엘)
- 개발 PC 주소: `http://localhost:3000`
- 주소는 글자 하나라도 다르면 안 됩니다. 끝에 `/`를 붙이지 마세요.

---

## 1. 카카오 (developers.kakao.com)

메뉴 이름은 카카오 디벨로퍼스 새 화면 기준입니다 (2026-11 공식 문서 확인).

1. **앱 만들기**: [앱 이름] `스터디AI` / [회사명] 상호 / [카테고리] 교육. 앱 아이콘은 선택(250KB 이하, 128×128 권장).
2. **[앱] > [플랫폼 키] > [REST API 키]**
   - [카카오 로그인 리다이렉트 URI]에 두 줄 → [저장]
     - `https://studyai-l12f.onrender.com/api/auth/kakao/callback`
     - `http://localhost:3000/api/auth/kakao/callback`
   - [클라이언트 시크릿]: 새 앱은 [활성화]가 처음부터 ON입니다. [코드]를 복사 → `KAKAO_CLIENT_SECRET`
   - REST API 키 값 복사 → `KAKAO_REST_API_KEY`
3. **[앱] > [플랫폼 키] > [JavaScript 키]**
   - [JavaScript SDK 도메인]: `https://studyai-l12f.onrender.com`, `http://localhost:3000`
   - [카카오 로그인 리다이렉트 URI]: 2번과 같은 두 줄 (폰에서 카카오톡 앱으로 바로 로그인할 때 이 키를 씁니다)
   - JavaScript 키 값 복사 → `KAKAO_JS_KEY`
4. **[카카오 로그인] > [사용 설정] > [상태]**: ON (꺼져 있으면 KOE004 오류)
5. **[카카오 로그인] > [동의항목]**
   - 닉네임: [설정] → [동의 단계] 선택 동의 / [동의 목적] "회원 식별 및 화면 표시" → 저장
   - 카카오계정(이메일): 비즈 앱으로 바꿔야 켤 수 있습니다(무료). 안 켜도 로그인은 됩니다.
     켜면 이메일로 먼저 가입한 사람이 카카오로 들어올 때 같은 계정에 연결됩니다.
6. 안 해도 되는 것: OpenID Connect, [앱] > [제품 링크 관리] > [웹 도메인] (로그인과 상관없음)

폰에서 동작: 카카오톡이 깔려 있으면 카카오톡 앱으로 넘어가 한 번 눌러 로그인(간편 로그인), 없거나 PC면 카카오 로그인 화면.

## 2. 네이버 (developers.naver.com)

1. **Application > 애플리케이션 등록** → 이용약관 동의 → 계정 정보 등록(휴대폰 인증 + 회사 이름. **휴대폰 인증은 본인만**)
2. [애플리케이션 이름]: `스터디AI` (네이버 로그인 화면에 보임, 10자 이내 권장)
3. [사용 API]: **네이버 로그인** → 제공 정보: 이메일 주소, 이름(또는 별명)만
4. [로그인 오픈 API 서비스 환경] > [환경 추가]를 두 번
   - **PC 웹**: [서비스 URL] `https://studyai-l12f.onrender.com` / [네이버 로그인 Callback URL] `https://studyai-l12f.onrender.com/api/auth/naver/callback`
     (최대 5개. 개발용 `http://localhost:3000/api/auth/naver/callback`도 받아 주면 추가)
   - **Mobile 웹**: 위와 같은 값
5. 등록 후 내 애플리케이션 > 스터디AI > 개요: Client ID → `NAVER_CLIENT_ID`, Client Secret [보기] → `NAVER_CLIENT_SECRET`
6. 처음엔 **개발 중** 상태라 [멤버관리]에 넣은 테스터 아이디만 로그인됩니다.
   모두에게 열려면 [검수요청]을 내고 승인을 받아야 합니다.

폰에서 동작: 네이버 로그인 화면에 **"네이버 앱으로 자동로그인"** 버튼이 같이 나옵니다(네이버 공식 가이드 5.3, 우리 쪽에서 `appscheme=true`를 붙임).
콘솔에 따로 켤 것은 없습니다. 웹에서 네이버 앱으로 "바로" 넘어가는 공식 방법은 없어서, 그 버튼을 한 번 누르는 방식입니다.

## 3. 구글 (console.cloud.google.com)

1. 새 프로젝트: `StudyAI`
2. **[Google 인증 플랫폼]** (예전 이름 "OAuth 동의 화면")
   - [브랜딩]: 앱 이름 `스터디AI`, 사용자 지원 이메일, 개발자 연락처 이메일.
     앱 홈페이지 `https://studyai-l12f.onrender.com`, 개인정보처리방침 `https://studyai-l12f.onrender.com/privacy`, 서비스 약관 `https://studyai-l12f.onrender.com/terms`.
     **로고는 올리지 마세요** (올리면 구글 검토를 기다려야 합니다).
   - [대상]: **외부** → **[앱 게시]** (프로덕션). "테스트" 상태면 등록한 사람만 됩니다.
   - [데이터 액세스]: 범위를 추가하지 않습니다 (기본 이메일·프로필만).
3. **[클라이언트] > [클라이언트 만들기]**: 애플리케이션 유형 **웹 애플리케이션**, 이름 `StudyAI Web`
   - [승인된 자바스크립트 원본]: `https://studyai-l12f.onrender.com`, `http://localhost:3000`, `http://localhost`
   - [승인된 리디렉션 URI]: 비워 둡니다.
   - 클라이언트 ID(`…apps.googleusercontent.com`) → `GOOGLE_CLIENT_ID`. 클라이언트 보안 비밀번호는 쓰지 않습니다.

폰·PC 동작: 구글 공식 버튼(흰색 둥근 버튼)과 One Tap(화면 위에 뜨는 계정 선택 창). 전에 구글로 들어온 기기에서는 누르지 않아도 다시 로그인됩니다(구글 자동 로그인, 직접 로그아웃한 뒤에는 꺼짐).

## 4. Render에 넣을 값

Render → `studyai` 서비스 → **Environment**에서 추가합니다. (`render.yaml`에 이름은 적어 두었지만, 이미 만든 서비스에는 자동으로 안 생깁니다.)

| 이름 | 어디서 | 없으면 |
|---|---|---|
| `KAKAO_REST_API_KEY` | 카카오 2번 | 카카오 버튼 안 보임 |
| `KAKAO_CLIENT_SECRET` | 카카오 2번 [클라이언트 시크릿] | 카카오 로그인 실패 (시크릿이 ON일 때) |
| `KAKAO_JS_KEY` | 카카오 3번 | 폰에서 카카오톡 앱 대신 카카오 웹 로그인 화면 |
| `NAVER_CLIENT_ID` | 네이버 5번 | 네이버 버튼 안 보임 |
| `NAVER_CLIENT_SECRET` | 네이버 5번 | 네이버 버튼 안 보임 |
| `GOOGLE_CLIENT_ID` | 구글 3번 | 구글 버튼 안 보임 |

`SOCIAL_LOGIN_MOCK`은 Render에 넣지 않습니다 (넣어도 운영에서는 무시됩니다).

## 5. 다시 로그인할 때

- 로그인은 60일 유지되고, 쓰는 동안은 계속 늘어납니다.
- 로그아웃하거나 기간이 지나도, 이 기기에서 마지막으로 쓴 방법을 기억해 그 버튼을 맨 위에 **"최근에 사용"** 표시와 함께 보여 줍니다.
  (예: "최근 로그인: 카카오 홍*동". 토큰은 저장하지 않고 가린 이름·이메일만 남깁니다.)
- "다른 계정으로 로그인"을 누르면 그 기억을 지웁니다.

## 6. 개발 PC에서 키 없이 시험하기

`.env`에 `SOCIAL_LOGIN_MOCK=1`을 넣고 `npm run dev`. 가짜 카카오·네이버·구글 버튼이 나옵니다.
카카오·네이버는 가짜 로그인 화면을 거치고, 구글은 로그인 창의 이메일 칸 주소로 들어갑니다.

## 계정 연결 규칙

- 같은 카카오·네이버·구글 계정은 항상 같은 스터디AI 계정으로 들어옵니다 (각 회사의 회원 번호로 찾음).
- 이메일로 먼저 가입한 사람이 같은 이메일로 소셜 로그인하면, 그 회사가 **확인한 이메일**일 때만 기존 계정에 연결합니다.
  - 구글: 항상 확인된 이메일만 받습니다 (확인 안 된 구글 계정은 거절).
  - 카카오: 카카오가 "유효·인증됨"이라고 한 이메일만 연결합니다.
  - 네이버: 확인 여부를 알려 주지 않아서 자동 연결하지 않습니다. 같은 이메일 계정이 이미 있으면 "처음 가입한 방법으로 로그인해 주세요"라고 안내합니다.
- 소셜로만 가입한 계정은 비밀번호가 없습니다. 이메일 칸으로 로그인하려 하면 어느 버튼을 누르면 되는지 알려 줍니다.
